1.what is css? what is full form of css?
Cascading Style Sheets. It is a standard stylesheet language used to design, style, and layout the visual presentation of web pages.While HTML is used to structure a webpage (like adding text, paragraphs, and links), CSS is used to control how those elements actually look on the screen. 


2.What is Cascading in CSS? Give a real-time example.
Cascading in CSS is the algorithm the browser uses to resolve styling conflicts when multiple rules target the same HTML element. It relies on three primary factors: importance (!important rules), specificity (how targeted a selector is), and source order (the latest rule wins if a tie occurs).


3. What is the difference between Cascading and Specificity?
Cascading is the main process that looks at order, origin, and importance to solve style clashes, while specificity is the scoring tool used inside that process to rank how strong a selector is.
CascadeThe big manager: The cascade looks at all rules and decides the final winner.Order matters: If two rules have the same score, the one written last wins.Source and origin: It checks where the style comes from (like browser defaults or user code).
SpecificityThe point system: Specificity gives a score based on the type of selector used.ID beats Class: An ID selector beats a class, and a class beats a simple HTML tag name.Tie breaker: It only steps in when different selectors target the same item.


4.What are the three types of CSS? Which one is recommended in real-time projects and why?
The three types of CSS are Inline CSS, Internal (Embedded) CSS, and External CSS. External CSS is the heavily recommended method for real-time production projects.
1. Inline CSSWritten directly inside individual HTML elements using the style attribute.Example: <p style="color: blue; font-size: 16px;">Text</p>Scope: Affects only that single specific HTML element.
2. Internal or Embedded CSSDefined inside a <style> tag, which is placed inside the <head> section of an HTML document.Example:html<head>
  <style>
    p { color: blue; }
  </style>
</head>
3. External CSSWritten in a completely separate file with a .css extension (e.g., styles.css) and linked to the HTML file via a <link> tag in the <head> section.Example: <link rel="stylesheet" href="styles.css">

8.Explain the CSS Box Model. Name its four parts.

The CSS Box Model is a concept that describes how every HTML element is displayed as a rectangular box. It determines the space an element occupies on a webpage.
Four Parts of the CSS Box Model
1.Content
The actual text, image, or other content inside the element.
You can control its size using width and height.
2.Padding
The space between the content and the border.
It creates inner spacing around the content.
3.Border

The line that surrounds the padding and content.
You can set its width, style, and color.
4.Margin

The space outside the border.
It creates distance between the element and other elements.

9.What is the difference between Padding and Margin?

Padding	                                                     Margin
Space inside the border	                                     Space outside the border
Increases the space between the content and the border	     Increases the space between the element and other elements
Background color applies to the padding area	             Background color does not apply to the margin area
Does not create space between neighboring elements	     Creates space between neighboring elements

10.What is box-sizing:border-box? Why is it recommended?

The box-sizing: border-box property changes how the browser calculates an element's total width and height.By default, CSS uses box-sizing: content-box, where the width and height apply only to the content. Padding and border are added to the outside, making the element larger.With box-sizing: border-box, the specified width and height include the content, padding, and border.
recommended:
1.Keeps layouts predictable.
2.Makes responsive design easier. 
3.Reduces layout issues. 
4.Simplifies calculations.

11.Explain the difference between the following display properties:
block
inline
inline-block

1. display: block
Starts on a new line.
Occupies the full width available.
You can set width and height.

2. display: inline
Does not start on a new line.
Takes only the space required by its content.
width and height have no effect.

3. display: inline-block
Does not start on a new line.
Allows you to set width and height.
Combines the features of both inline and block.

14.Explain Flexbox.

What are:

Flex Container

Flex Item

Main Axis

Cross Axis

Flexbox is a CSS layout model used to arrange, align, and distribute space between elements efficiently. It makes it easy to create responsive layouts without using floats or positioning.

1. Flex Container

A Flex Container is the parent element with display: flex or display: inline-flex.

It controls the layout of all its child elements.

2. Flex Item

A Flex Item is any direct child of a flex container.

In the example above:

Item 1 → Flex Item
Item 2 → Flex Item
Item 3 → Flex Item

These items are arranged according to the flex container's properties.

3. Main Axis

The Main Axis is the primary direction in which flex items are placed.

By default (flex-direction: row), the main axis is horizontal (left to right).
If flex-direction: column is used, the main axis becomes vertical (top to bottom).

4. Cross Axis

The Cross Axis is always perpendicular to the main axis.

If the main axis is horizontal, the cross axis is vertical.
If the main axis is vertical, the cross axis is horizontal.
