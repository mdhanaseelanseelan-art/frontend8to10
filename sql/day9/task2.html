Cross and Self Joins

Use SELF JOIN to model organizational reporting trees and CROSS JOIN for all combinations.

📁 Day Overview Task 1: Customers Without Orders (LEFT JOIN) Task 2: Cross and Self Joins 📜 Raw outer_joins.sql
📝 SQL Solution Code
task2_solution.sql 
SELECT 
    emp.full_name AS "Employee",
    emp.job_title AS "Role",
    COALESCE(mgr.full_name, 'Top Level Executive') AS "Reports To"
FROM staff emp
LEFT JOIN staff mgr 
    ON emp.manager_id = mgr.staff_id;
