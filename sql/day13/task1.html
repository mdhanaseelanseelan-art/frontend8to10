Stored Procedure for User Signup

Encapsulate business logic within reusable stored procedures taking IN and OUT parameters.

📝 SQL Solution Code
task1_solution.sql 
DELIMITER //
CREATE PROCEDURE AddCustomerOrder(
    IN cust_id INT,
    IN order_total DECIMAL(10,2),
    OUT generated_order_id INT
)
BEGIN
    INSERT INTO orders (customer_id, total_amount, order_date, status)
    VALUES (cust_id, order_total, NOW(), 'Pending');
    
    SET generated_order_id = LAST_INSERT_ID();
END //
DELIMITER ;
