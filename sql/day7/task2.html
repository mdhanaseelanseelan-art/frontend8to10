CHECK & UNIQUE Constraints

Enforce data integrity rules using CHECK, NOT NULL, and UNIQUE constraint specifications.

📁 Day Overview Task 1: Relational Schema with Foreign Keys Task 2: CHECK & UNIQUE Constraints 📜 Raw constraints.sql
📝 SQL Solution Code
task2_solution.sql 
CREATE TABLE user_accounts (
    user_id INT PRIMARY KEY,
    username VARCHAR(30) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    age INT CHECK (age >= 18),
    credit_score INT CHECK (credit_score BETWEEN 300 AND 850)
);
